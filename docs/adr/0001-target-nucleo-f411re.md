# Target NUCLEO-F411RE with STM32CubeIDE and STM32CubeMX

For course compliance with 2110366 Embedded System Lab I, we selected the NUCLEO-F411RE (STM32F411RET6) board as the target microcontroller platform using STM32CubeIDE and STM32CubeMX. This provides official ST HAL driver integration, graphical pin/clock configuration via `.ioc`, and standard lab debugging workflows directly within `main.c` `USER CODE` sections.
