# Issue tracker: GitHub

Issues and specifications for this repository live in GitHub Issues. Use the `gh` CLI for issue creation, reading, labels, and GitHub-native blocking dependencies.

## Conventions

- Create issues in `worawalan-s/sensor-based-smart-light`.
- Represent a task dependency with GitHub's native **blocked by** relationship. When unavailable, state `Blocked by: #<number>` at the top of the issue body.
- Apply the `ready for agent` label only when an issue is sufficiently specified to implement.
- Pull requests are not a triage surface for this repository.

## When a skill says "publish to the issue tracker"

Create a GitHub issue.
