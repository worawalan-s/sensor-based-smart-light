# Triage labels

The engineering workflows use five canonical roles. This table maps them to the labels used in this repository.

| Canonical role | Repository label | Meaning |
| --- | --- | --- |
| `needs-triage` | `review needed` | A maintainer must prioritize it or decide the next step. |
| `needs-info` | `need details` | More information is required before implementation can proceed. |
| `ready-for-agent` | `ready for agent` | Fully specified and ready to implement. |
| `ready-for-human` | `team action needed` | A teammate must decide, approve, or perform physical work. |
| `wontfix` | `not planned` | Intentionally out of scope. |

When an engineering workflow refers to a canonical role, apply the corresponding repository label.
